# REPO-GUIDANCE behavior and oracle matrix

The maintainer approved the decisions in the governing spec on 2026-11-11,
before implementation. The oracles below are spec-derived from those decisions
and the named acceptance criteria. See [execution evidence](./evidence.md)
for commands, results and coverage details.

| AC-001 | Opted-in real checkout and separate replicas (D-01) | Each execution sees only its own clone/worktree paths and bytes. Root guidance uses the first present unblocked candidate. An invalid chosen file produces an omission. Immediate packages appear in the catalogue. Nested files, imports and other unsupported sources contribute no guidance. | spec-derived (D-01, AC-001) | Discovery unit and clone/worktree engine integration | Discovery, clone and worktree checks passed |
| AC-002 | Defaults, inheritance, disable, source blocks, and concurrent saves (D-02) | Existing and new graphs default off. The node may inherit, disable or narrow.
